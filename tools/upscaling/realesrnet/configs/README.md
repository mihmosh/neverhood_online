# Animation Experiment Configuration

[seedvr2-probe-v1.json](seedvr2-probe-v1.json) preserves the sanitized settings and
outcomes of the initial API experiment. It is an evidence record, not an
executable deployment instruction or permission to create paid predictions.

The common, cross-branch [manifest contract](../../configs/manifest.md) remains
outside this folder. Real source catalogs, per-frame mappings, worker checkpoints
and output receipts remain in ignored local storage, not in committed config.

Pin model/runner/checkpoint hashes, input identity, geometry and masks separately
from preview presentation. Mark provider-hidden choices and unverified runtime
contexts as unknown. Never include API keys, signed URLs, base64 media or raw
prediction responses here.
