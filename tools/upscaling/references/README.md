# Photographic References

[backstage](backstage/README.md) contains the deliberately selected existing
production/set-photo candidates approved by the maintainer for repository
inclusion. These are a media exception, not permission to bulk-import the game,
generated frames, private experiments or model weights.

Use reference-catalog IDs and hashes in experiment manifests. Their role is to
guide material and appearance, not replace source gameplay geometry. Selection
of a reference and actual attachment to a model must be recorded separately.

Photographic provenance and licensing are not inferred from the project's
software license. Unknown fields remain unknown in the catalog.
