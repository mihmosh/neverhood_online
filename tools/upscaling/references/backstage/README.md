# Backstage / Physical-Set References

Five existing JPEGs are copied byte-for-byte from the maintainer's local
`private-assets/backstage_hires` collection, following explicit approval to
include these references in the repository. Original files remain untouched.

[catalog.json](catalog.json) records filenames, byte sizes, SHA256 and visible
subjects. These look like photographs of physical sets/puppets, but original
photographer, source URL, capture date and camera-original status are unverified.
Filenames alone are not evidence of a particular social-media source.

These photographs are not relicensed by the repository's software license.
Do not describe them as public domain, authenticated camera originals or newly
generated artwork. Update the provenance when a reliable source is established.
